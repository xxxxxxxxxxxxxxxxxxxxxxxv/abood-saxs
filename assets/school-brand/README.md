# School identity assets

Place the school's official files in this folder when they are available:

- `logo.png` — login, navigation, and printed school documents
- `icon.png` — browser favicon
- `apple-touch-icon.png` — mobile home-screen icon
- `school-photo.jpg` — optional school photograph

No replacement artwork is supplied. The interface displays the school name
without a logo until an official image is provided. Paths can be changed in
`config.inc.php` using the `$SchoolBrandLogo`, `$SchoolBrandIcon`,
`$SchoolBrandTouchIcon`, and `$SchoolBrandSchoolImage` settings.
